XBlog使用说明

平台地址

找我获取账号，然后登录进入平台： https://xblog.integer.click
安全建议： 绑定账号2FA

必要配置

该步骤只需要操作一次

获取 github token

  1. 登录github: https://github.com

  2. 进入：https://github.com/settings/personal-access-tokens

  3. 如图

  4. 按下面的提示填写：
    Token Name: 随便填
    Description： 随便填
    Resource owner： 不动，使用默认的即可
    Expiration： 选择 No expiration
    Repository access：选择 All repositories
    Permissions：点击 Add Permissions 按钮勾选： Actions、Administration、Contents、 Pages，勾选完点确认之后，会再自动带出来一个： Metadata
    选完之后这四项后面会出现一个 Access: Read-Only 的下拉选项，全部下拉选择 Read and Write， 如图：

    然后点击 Generate token 按钮，再在弹窗里面点击 Generate token 按钮

  5. 上一步完成之后会进入Token列表页，这时候就能看到申请的 Token了，必须马上复制保存，后续刷新页面不会再出来了，如果没复制到，再申请一个就行了

设置 github token

  1. 再次进入： https://xblog.integer.click
  2. 进入： 博客-Github
  3. 点击右上角的“添加配置”按钮
  4. 配置名称随意填写，Personal access token 填写上一步获取到的Github Token
  5. 点击保存并返回
  6. 点击列表中刚才添加的数据后面操作列中的“检测连接”按钮， 出现账号：通过即可，其他几项可以忽略

创建站点

思想准备

先想清楚博客的名字和域名，域名可以在这里查价： https://www.spaceship.com/zh/domain-search/?query=&tab=domains
建议使用 .com .net .blog 这三个后缀的域名

准备仓库

进入系统： 博客-GitHub， 点击配置后面操作列中的查看仓库，点击创建仓库，输入仓库名称（随意，后续有多个仓库了，自己能区分就行），可见性选公开，填完后点创建并返回

准备域名

进入系统：博客-域名管理，点击域名查询，输入之前看好的可用的域名，点击查询可用性，等结果出来点击域名后面的购买按钮
注意： 如果要填域名价格，请点击注册价格列下面的 查看官方价格，将获取到的价格填入（如果价格是rmb，需要换算成美元）
核对订单中，年限填1年，点击立即购买
回到全部域名，如果没看到刚才购买的域名，一般等几秒再刷新就会出来

创建站点

  1. 进入系统： 博客-站点管理，点击创建站点
  2. 基本信息： 域名选择刚注册的域名，二级域名可以不填，填的话建议填 www
  3. GitHub发布： 选择GitHub账号，之后选择前面准备的仓库，勾选"同时配置并部署 GitHub Pages"
  4. 其他的信息自己看着摸索
  5. 写完文章之后等操作之后，可以进入发布站点环节
